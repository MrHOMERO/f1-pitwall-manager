# F1 Manager 2026 Simulator

Simulador interactivo en consola programado en Python para la temporada 2026 de Fórmula 1. Asume el rol de Team Principal, elige una de las 11 escuderías oficiales, gestiona a tu piloto y mejora el rendimiento de tu monoplaza.

## 🏎️ Características
- **Parrilla 2026 Completa:** 11 escuderías y 22 pilotos oficiales (incluye la escudería Cadillac).
- **Sistema de Puntos de Desarrollo (RP):** Obtené recompensas según tu posición final en cada Gran Premio.
- **Taller de I+D:** Invertí tus RP para mejorar Alerones, Motor, Frenos y Suspensión.
